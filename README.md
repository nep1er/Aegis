AEGIS - приложение для управления Спец-стоянками (штраф стоянками).

Позволяет:
1) Работа оператора. Регистрация авто и выдача с учетом данных от Госс номерах и VIN, владельце.
2) Работа администратором. Редактировать парковки, учетные записи. Полная аналитика и пробивание истории авто.
